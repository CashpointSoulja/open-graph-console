# Jobs to be done

- When an insurer changes a product, I want the graph updated within 24 hours, so every agent answer stays true.
- When a score influences a recommendation, I want it explainable line by line, so a regulator can audit it.
- When a beta channel wants the graph, I want a clear freshness gate, so we never ship an answer we cannot stand behind.
- When an eval goes red, I want one-click rollback, so a bad deploy never reaches a customer twice.
- When a miss happens, I want it logged and converted into a system change, so the same miss cannot repeat.
