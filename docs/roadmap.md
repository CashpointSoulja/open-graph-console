# Roadmap - first 90 days

## Weeks 1-2: baseline
Instrument freshness end to end; publish the 24-hour guarantee internally; stand up the incident log.

## Weeks 3-6: accuracy operation
Per-meaning change detection for the top 5 insurers; review queue staffed to the 4-hour SLA; drift alerts on live agent traffic.

## Weeks 7-10: explainable scoring
Score explanations shipped; eval suite wired into release; rollback drill run twice.

## Weeks 11-13: distribution gates
Companion to autopilot behind the freshness guarantee; chat app and quote integration graduate from beta only when the guarantee holds for 30 consecutive days.
